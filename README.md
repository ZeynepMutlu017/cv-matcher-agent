# CV Matcher Agent

An AI-powered CV and job description matching system that combines Machine Learning and Large Language Models to provide detailed candidate-job fit analysis.

## Features

- **ML-based job role prediction** — Logistic Regression classifier trained on 998 candidate profiles across 20 job categories
- **Semantic skill gap analysis** — Azure OpenAI GPT analyzes matched and missing skills
- **Match scoring** — 0-100 compatibility score based on CV and job description
- **Career recommendations** — Personalized improvement suggestions
- **Interactive web interface** — Built with Streamlit

## Tech Stack

- Python
- Azure OpenAI Service (GPT + text-embedding-3-small)
- scikit-learn
- Streamlit
- NumPy, Pandas
